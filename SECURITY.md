# Security and privacy reports

Do not include secrets, health data, real Nightscout addresses or device identifiers in public issues. For ordinary bugs, reproduce with sample data or a disposable test server.

For vulnerabilities, use GitHub's private vulnerability reporting option if it is available under this repository's Security tab. If it is unavailable, ask the maintainer for a private reporting channel without posting exploit details or private data publicly.

TrioPC currently performs Nightscout reads and local simulation only. Live insulin-delivery commands are not implemented. Communication errors and missing history must never be treated as proof of zero insulin delivery.
